Five scan modules, one pipeline.

Every scan runs all five modules below in sequence against your target and streams findings back to you as they're discovered.

01

Security Headers

Checks the target's HTTP response for well-known protective headers — Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, and Strict-Transport-Security — and flags any that are missing.

misconfigurationlow effort, quick win
02

SQL Injection

Submits known error-triggering payloads to every form on the page and inspects the response for database error signatures (MySQL, PostgreSQL, SQLite and others).

injectionerror-based detection
03

Cross-Site Scripting (XSS)

Injects a harmless, uniquely-marked script payload into every form field and checks whether it comes back unescaped in the rendered page.

injectionreflected XSS
04

IDOR

Follows links that contain a numeric identifier and swaps the ID for nearby values, flagging cases where every value returns data with no visible authorization check.

access controlneeds manual review
05

API Security

Probes a list of common API paths (/api/users, /api/admin, and more) with no Authorization header, flagging any endpoint that returns JSON data unprotected.

authenticationexposed endpoints

How a scan runs

STEP 1

Enter a target

STEP 2

Pipeline runs

All five modules run one after another against that target.

STEP 3

Watch it live

Every request and result streams into the dashboard terminal.

STEP 4

Review findings
