Why RadarScan exists

RadarScan is a graduation project built to show how a small pipeline of independent scan scripts can be orchestrated behind a single dashboard, with results streamed live instead of delivered as a static report.

What it is

A Flask web app that lets you register, enter a target URL, and run five sequential security checks against it — security headers, SQL injection, XSS, IDOR, and exposed API endpoints — while watching every request and result appear in real time.

What it isn't

It's not a replacement for tools like Burp Suite or OWASP ZAP, and it doesn't claim full coverage of any vulnerability class. Its value is in demonstrating the architecture — orchestration, live logging, accounts, plans, and reporting — around a set of intentionally simple scan modules.

Responsible use

  • Only scan sites you own or are explicitly authorized to test.
  • Use the bundled vulnerable_target/ app to try the scanners safely.
  • Scanning a site without permission may be illegal in your country.

Built by

A student team as a graduation project. See the project's README for the current roadmap and how to contribute.
